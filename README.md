# ETF 智能推荐工具

基于 **DeepSeek模型 多维度分析** 和 **实时财经资讯** 的 ETF 推荐系统。帮助投资者根据当前市场环境和投资周期智能筛选最具潜力的 ETF。

## 背景
因为想跟踪行业热点赚钱，于是盯上了ETF这个好工具。通过高行业集中度以及多股分散风险，ETF可以很好地反映一个行业/主题的投资前景，为此开发这个小工具。感谢腾讯和东财api！本工具未做任何专业部署上线，开箱后在环境中配置DeepSeek api密钥后即可食用。

## 核心特性

### **AI 多维评分**
- **相关度评分** — ETF 与财经资讯的关联强度
- **影响度评分** — 资讯对市场可能造成的价格变化
- **持续度评分** — 资讯影响的时间长度
- **综合评分** — 加权融合三个维度：40% 相关度 + 35% 影响力 + 25% 持续时间（可以根据自己理解调整）

### **投资周期智能筛选**
四档投资策略，可自行筛选，调整 ETF 筛选条件（同样可以根据自己对流动性理解调整）：

| 周期 | 换手率范围 | 价格波动 | 资讯影响时效  |
|------|----------|--------|---------|
| **超短线** | 2.0% - 15.0% | 下跌不超 1% | 0-2 天   |
| **短线** | 1.0% - 8.0% | 下跌不超 2% | 3-7 天   |
| **中线** | 0.5% - 3.0% | 下跌不超 3% | 8-15 天  |
| **长线** | 0.5% - 2.0% | 下跌不超 5% | 15-60 天 |


### **实时财经资讯处理**
- 自动爬取腾讯财经资讯
- AI 结构化处理（标题、摘要、关键点、涉及行业）
- 计算资讯影响力评分
- 关键词自动匹配 ETF

### **实时行情更新**
- 每 3 秒自动更新 ETF 价格、涨跌幅
- 早上九点与下午三点资讯与推荐列表将自动刷新

## 快速开始

### **1. 环境要求**
- Python 3.9+
- pip

### **2. 安装依赖**
```bash
pip install -r requirements.txt
```

### **3. 配置 API Key**
创建 `.env` 文件：
```env
DEEPSEEK_API_KEY=your_api_key_here（填入自己的api密钥）
DEEPSEEK_BASE_URL=https://api.deepseek.com/v1
DEEPSEEK_MODEL=deepseek-chat
```

### **4. 启动应用**
```bash
python new_app.py
```

打开浏览器：http://127.0.0.1:5000

## 核心算法

### **四阶段推荐流程**

#### **第一阶段：硬性筛选**
根据投资周期过滤 ETF（换手率、价格波动）

#### **第二阶段：关键词匹配**
从资讯提取关键词，构建 ETF 候选池

#### **第三阶段：AI 多维评分**
DeepSeek 对每个 ETF 计算相关度、影响度、持续度

#### **第四阶段：投资周期加权**
根据用户选择的投资周期调整推荐优先级
